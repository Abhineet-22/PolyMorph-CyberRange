⚔️ Attack Vectors in This Lab

          

            

              1. Pre-signed URL Upload Bypass
              
Direct client-to-storage PUT allows uploading unauthorized payloads without passing through application middleware.

            

            

              2. Parser Differential → Background Archive Extraction
              
python-magic validates image header (passes upload filter); background worker invokes zipfile to unpack payload (executes Zip-Slip / parser mismatch).

            

            

              3. Public Storage MIME Confusion
              
Objects served directly from S3 lack X-Content-Type-Options: nosniff and Content-Disposition: attachment, allowing polyglot script execution in browsers.
