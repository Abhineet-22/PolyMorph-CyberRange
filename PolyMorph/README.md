# PolyMorph

**PolyMorph** is a powerful polyglot file construction framework. It allows you to build files that are simultaneously valid in multiple distinct file formats (e.g., a file that is both a valid PDF and a valid ZIP archive).

PolyMorph achieves this by combining files using various strategies based on the *parsing contracts* of the target formats. The tool also includes a dynamic probing engine to empirically discover what data parsing tools tolerate.

## Key Features

- **Polyglot Construction (`build`)**: Intelligently merge two files into one polyglot output using automated strategy selection.
- **Dynamic Format Probing (`probe`)**: Empirically analyze an unknown file format to discover its structural properties (append-tolerance, prepend-tolerance, etc.). It validates assumptions using a sample file against real parser executables.
- **Format Discovery & Validation**: Automatically detect formats and generate parsing templates (`FormatSpec`). Can leverage local heuristics or a `SuggestionEngine` via LLMs and Web Searches to suggest correct validation tools.
- **Format Registry (`formats` & `info`)**: Inspect the registered knowledge base of format structures, parsing rules, and viable polyglot strategies between format pairs.
- **Format Validators (`validation`)**: Post-construction verification ensures the generated polyglots are actually parseable by the intended decoders.

## Project Structure

- **`cli.py`**: The main entry point for the PolyMorph command-line interface. Built using `click` and `rich`.
- **`core/`**: The orchestration and decision-making logic.
  - `constructor.py`: The top-level orchestrator that coordinates the build process.
  - `combination_engine.py`: Selects and validates the best strategy for a given format pair.
  - `format_registry.py`: The knowledge base (`FormatSpec`) containing details about where parsers begin, end, and what they tolerate.
- **`formats/`**: Implementations of specific format handlers (e.g., `pdf.py`, `zip_fmt.py`).
- **`probe/`**: The probing and discovery engine.
  - `probe_engine.py`: Orchestrates probes for format exploration.
  - `auto_detector.py`: Detects file types and recommends validators.
  - `probes/`: Specific probe strategies like `append_probe` and `prepend_probe`.
  - `suggestion_engine/`: Connects to LLMs and search engines to resolve unknown formats.
- **`strategies/`**: Implementations of polyglot combination strategies.
  - `append.py`: Strategy that appends Format B after Format A's logical EOF marker.
  - `base.py`: The base class for defining strategies.
  - *(Planned)* `prepend`, `inject`, `nest` strategies.
- **`validation/`**: Verifies that generated byte sequences conform to real format parsers.
  - `format_validator.py`: Dispatch table to route raw bytes to specific validators.
- **`evasion/`**: *(Planned)* Modules intended for evading detection logic or obfuscating payloads.

## Requirements

Install the required dependencies using `pip`:

```bash
pip install -r requirements.txt
```

**Key Dependencies**:
- `click`, `rich`: For the command-line interface.
- `pypdf`, `py7zr`, `rarfile`, `zipfile` (built-in): For archive and document parsing.
- `pyelftools`, `pefile`, `macholib`: For executable parsing.
- `duckduckgo_search`: Used by the `SuggestionEngine` for web-based format discovery.

## Usage

PolyMorph is invoked via its CLI. Below are the primary commands.

### 1. Building a Polyglot (`build`)

Construct a polyglot file from a host (`FILE_A`) and a payload (`FILE_B`). PolyMorph will select the best strategy automatically or you can force one.

```bash
# Auto-select strategy (e.g., PDF + ZIP)
python -m polymorph build document.pdf archive.zip -A pdf -B zip -o polyglot.pdf

# Force a specific strategy
python -m polymorph build doc.pdf arc.zip -A pdf -B zip -s append -o polyglot.pdf
```

### 2. Probing a Format (`probe`)

Empirically probe a format's parsing contract.

```bash
# Verify a known format against its registered FormatSpec
python -m polymorph probe -f pdf -s sample.pdf

# Discover a new format and generate a FormatSpec template using a known magic byte
python -m polymorph probe -f elf -s sample.elf --magic-bytes 7f454c46

# Probe an unknown format and optionally query an LLM for parser recommendations
python -m polymorph probe -f unknown_fmt -s sample.bin --suggest --llm ollama

# Update the FormatRegistry with measured results
python -m polymorph probe -f elf -s sample.elf --validator-cmd "readelf -h {file}" --update
```

### 3. Listing Formats (`formats`)

View the properties of all currently registered formats.

```bash
python -m polymorph formats
```

### 4. Strategy Info (`info`)

List the viable strategies between a pair of formats without actually building the file.

```bash
python -m polymorph info -A pdf -B zip
```
